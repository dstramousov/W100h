# W100h: интеграция с Linux

README проекта зафиксирован и не меняется; здесь лежат только команды Linux-интеграции.

## Установка

Сначала собрать W100h:

```bash
./m
```

Потом зарегистрировать приложение для текущего пользователя:

```bash
./desktop
```

Команда делает четыре вещи без `sudo`:

1. регистрирует W100h как обычное desktop-приложение;
2. регистрирует тип `audio/x-pt3` для файлов `*.pt3`;
3. назначает W100h приложением по умолчанию для PT3;
4. если установлен Midnight Commander, добавляет отдельное правило `Enter -> W100h` в `~/.config/mc/mc.ext.ini`.

### Nautilus

После установки двойной клик по `.pt3` передаёт полный путь W100h. Поскольку запуск с конкретным файлом уже является режимом autoplay, выбранная композиция сразу начинает играть.

Если Nautilus был открыт во время установки, достаточно закрыть и снова открыть окно Files. Проверить ассоциацию можно командой:

```bash
xdg-mime query default audio/x-pt3
```

Ожидаемый ответ:

```text
org.w100h.player.desktop
```

### Midnight Commander

После `./desktop` перезапустить `mc`. `Enter` на `.pt3` запускает W100h с выбранным файлом и сразу возвращает управление Midnight Commander.

Правило добавляется как управляемый блок и не заменяет остальные пользовательские ассоциации MC.

## Удаление регистрации

```bash
./desktop --uninstall
```

Только desktop/MIME, без изменения конфигурации Midnight Commander:

```bash
./desktop --no-mc
./desktop --uninstall --no-mc
```
